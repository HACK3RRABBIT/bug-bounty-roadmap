Linux & the Command Line

Without terminal fluency you can't run any hacking tool correctly

0/10 days
Day 6Hands-on

Linux basics: filesystem and core commands + OverTheWire Bandit — levels 0-2

(1) Practice the 'Linux Basics' chapter: ls, cd, pwd, cat, cp, mv, rm, mkdir, man. Use man/--help instead of Google for every command. (2) SSH into the Bandit server (level0/level0, password: bandit0) and solve the first three levels. Learn to find hidden files, oddly named files, and command output.

↗ Linux Journey — Grasshopper↗ TryHackMe — Linux Fundamentals Part 1 (free)↗ OverTheWire Bandit↗ Bandit Level 0
⏱ 4h estimated
Day 7Hands-on

Bandit — levels 3-6

Practice hidden files, recursive search with find, and filtering by type/size/permission. Combine find and grep.

↗ Bandit Level 3
⏱ 2h estimated
Day 8Hands-on

Bandit — levels 7-10 + Permissions, ownership and environment variables

(1) Practice advanced grep, archive handling (tar/gzip/bzip2), and Base64/binary files. (2) Learn rwx, numeric/symbolic chmod, chown, and environment variables (PATH, env), then solve Bandit levels 11-14.

↗ Bandit Level 7↗ Bandit Level 11
⏱ 4h estimated
Day 9Hands-on

SSH keys, ports and processes

Generate an SSH key with ssh-keygen, connect with a private key, inspect running processes (ps, netstat/ss). Solve Bandit levels 15-18.

↗ Bandit Level 15
⏱ 2h estimated
Day 10Hands-on

Cron jobs, setuid, and simple scripting

Understand cron, setuid binaries, and how a binary can run as a different user. Solve Bandit levels 19-23.

↗ Bandit Level 19
⏱ 2h estimated
Day 11Hands-on

Netcat and basic network communication + Git from a security angle + unusual binaries

(1) Practice nc: opening a listening port, sending/receiving data, simulating a simple client-server. Solve Bandit levels 24-27. (2) Learn Git history, exposed .git/ repos, and recovering data from old commits — directly useful for finding exposed .git/ in bug bounty. Solve Bandit levels 28-31.

↗ Bandit Level 24↗ Netcat guide↗ Bandit Level 28

Networking & the HTTP Protocol

The web runs on HTTP; if you don't understand HTTP, you can't understand any web vulnerability

0/10 days
Day 16Learn

OSI and TCP/IP models + DNS from scratch

(1) Learn the OSI/TCP-IP layers, TCP vs UDP, and the concept of a port. Write the 7 OSI layers from memory in Obsidian. (2) Learn how DNS works, record types (A, AAAA, CNAME, MX, TXT, NS), and dig/nslookup — test them on real domains.

↗ TryHackMe — Pre Security Path (free)↗ Cloudflare — What is DNS (free)↗ TryHackMe — DNS in Detail
⏱ 4h estimated
Day 17Learn

HTTP from scratch — methods and status codes

Read MDN in full on GET/POST/PUT/DELETE/PATCH/OPTIONS/HEAD, request/response structure, and status codes (2xx-5xx).

↗ MDN — HTTP Overview (free)↗ MDN — HTTP Status Codes
⏱ 2h estimated
Day 18Learn

HTTP headers and cookies

Learn the important security headers (Cookie, Set-Cookie, Authorization, Content-Type, Host, Referer, Origin, CSP, HSTS). Open a real site with Burp or DevTools and identify every header of one request.

↗ MDN — HTTP Headers↗ MDN — HTTP Cookies
⏱ 2h estimated
Day 19Hands-on

Install and set up Burp Suite Community + Hands-on Burp Suite: Proxy and Repeater

(1) Install Burp Suite Community (free), point your browser's proxy at it, install its CA certificate, and intercept your first HTTPS traffic. (2) Practice the Proxy and Repeater tabs against a test site (e.g. PortSwigger labs): intercept a request, send to Repeater, modify parameters, resend.

↗ Download Burp Suite Community (free)↗ PortSwigger — setting up Burp with Firefox↗ PortSwigger Academy — Burp Suite Essentials
⏱ 4h estimated
Day 20Learn

HTTPS/TLS in plain terms

Understand the TLS handshake, digital certificates, and why HTTPS blocks naive interception (conceptual level, not the math).

↗ Cloudflare — What is TLS (free)
⏱ 1h estimated
Day 21Hands-on

REST APIs and JSON

Learn APIs, REST, and JSON. Use Burp against a free public API (e.g. JSONPlaceholder) and rebuild GET/POST requests in Repeater.

↗ JSONPlaceholder — free test API↗ MDN — Working with JSON
⏱ 2h estimated
Day 22Hands-on

Web servers: Apache and Nginx + Wireshark and network traffic analysis

(1) Learn the difference between Apache and Nginx, virtual hosts, reverse proxies, and basic config files — essential later for SSRF and request smuggling. (2) Install Wireshark and capture your own browser traffic. Find and inspect HTTP and DNS packets in it.

↗ DigitalOcean — free Apache vs Nginx comparison↗ Nginx — official docs (free)↗ Download Wireshark (free)↗ TryHackMe — Wireshark: The Basics
⏱ 4h estimated
Day 23Hands-on

Nmap: port and service scanning

Practice a basic nmap scan (-sV, -sC, -p-) against a legal target (e.g. scanme.nmap.org) and interpret the output.

↗ Nmap — official reference guide (free)
⏱ 2h estimated
Day 24Hands-on

TryHackMe: Web Fundamentals — How the Web Works

Finish the starter room of the Web Fundamentals path: browsers, servers, and the full lifecycle of a web request, from a security lens.

↗ TryHackMe — How Websites Work (free)
⏱ 2h estimated
Day 25Review

Mini project: map a full HTTP request

↗ Excalidraw (free, online)
